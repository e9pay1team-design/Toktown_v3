# TokTown (톡타운) — 평가용 인터랙티브 데모

결제 서비스 '톡페이'의 확장 생태계 **TokTown**의 사내/투자 평가용 데모입니다.
지도·맛집 탐색·커뮤니티를 '동물의숲' 스타일 마을 세계관으로 감싸고, 기존 서비스의 실물
**톡페이 선불카드**(폰에 갖다 대면 충전되는 NFC 카드)로 온·오프라인을 연결하는 서비스의
핵심 루프를 브라우저에서 체험할 수 있습니다.

> 기획 근거: `toktown_기획문서_v1.7` · 구현 규칙: `toktown_구현브리프` (두 문서가 이 데모의 명세입니다)
> 현행 구현 기준 역정리 기획서: [`docs/toktown_기획서_역정리.md`](docs/toktown_기획서_역정리.md)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 → 데스크톱 화면 중앙의 **모바일 프레임(390×844)** 안에서
앱이 실행되고, 프레임 밖에 시연용 **데모 컨트롤 패널**이 표시됩니다.

- 로그인/서버/외부 연동 없음 — 모든 데이터는 목업(`src/mock/`)이며 상태는 localStorage에 저장됩니다.
- 모든 그래픽은 코드로 생성한 SVG입니다(외부 이미지 0장).
- **앱 전역 한/영 언어 모드** — 우상단 `한 | EN` 토글(온보딩 포함 상시)로 UI·매장/NPC 콘텐츠·
  캔버스 라벨·지도 마커까지 즉시 전환됩니다(외국인 대상 서비스 전제). 리뷰·커뮤니티 글은
  앱 언어와 일치하는 버전이 기본 표시되고 원문/번역 토글을 제공합니다.
- 지도 배경은 **코드 내장 일러스트 벡터 지도**(주요 도로·명동 골목 그리드·청계천·남산공원,
  데모 시드 좌표에 앵커링한 근사 지리)를 Leaflet 캔버스 타일로 직접 그립니다 — 외부 타일
  서버 의존이 없어 웹 공유 샌드박스·오프라인에서도 항상 보이고, 매장 POI 아이콘 없이
  톡타운 자체 SVG 마커가 매장 표시를 전담합니다. 실서비스 전환 시 네이버/카카오 지도
  SDK로 교체 예정입니다.
- 폰 프레임 안에서 모든 정상 조작이 가능합니다 — 지도 좌측 하단 **가상 조이스틱**으로 내
  위치 이동(걷기 배속), 우측 상단 🎛️ 토글로 **데모 패널 숨김/표시**(좁은 화면 기본 숨김).
  점프 재현·날짜 +1·Event Map·데모 리셋 같은 치트성 조작만 패널에 남습니다.

## NFC 키링 리다이렉트 (vercel.json)

실물 NFC 키링 20개에는 `/k/01` ~ `/k/20` URL을 굽습니다. Vercel 배포에서 이 경로는
전부 데모 앱 메인으로 **임시(비영구) 리다이렉트**됩니다 — 키링을 다시 굽지 않고
`vercel.json`의 `destination` 값 하나만 바꾸면 목적지를 일괄 변경할 수 있습니다.

- `permanent: false` 유지 필수 — Vercel 은 이를 **307**(임시)로 응답하며, 301/308 과
  달리 브라우저에 캐싱되지 않아 이후 목적지 변경이 즉시 반영됩니다.
  (정확히 302 상태 코드가 필요하면 `permanent` 대신 `"statusCode": 302` 사용 — 두 필드는 동시 사용 불가)
- `destination` 은 `/` 고정 — 같은 Vercel 배포의 데모 메인으로 보내므로 재배포되어도
  갱신이 필요 없습니다. 데모를 다른 도메인으로 이전할 때만 절대 URL 로 교체하세요 —
  규칙은 `CLAUDE.md` 참조.
- 앱은 URL 경로 기반 라우팅을 쓰지 않으므로(zustand 탭 상태) `/k/*` 와 충돌하는
  내부 라우트는 없습니다.

## M1 체험 가이드 (약 2분)

1. **온보딩** — 캐릭터 파츠(피부/헤어/의상) 커스터마이징 → 닉네임 → 주민증 발급 연출 → 촌장 부엉 튜토리얼
2. **지도** — 시청~을지로3가~남산 도보권의 매장 핀 18곳, 까치 NPC(하루 2지점 로테이션), 랜드마크 4곳(명동성당·남산타워·청계천·광화문), 내 캐릭터 마커 탐색
3. **검색** — `미성옥` 검색(자동완성·최근 검색) → 매장 상세(혜택 뱃지·영업시간·주민 리뷰·방문 인증 뱃지)
4. **저장** — 상세에서 ❤️ 저장 → 칩 `저장` → `저장 목록 보기` → 지도에서 보기

## M2 체험 가이드 (약 3분)

1. **출석** — 홈 진입 시 출석 팝업 → 도장 찍기(+10 톡큰). 패널 `날짜 +1` 후 연속 출석 시연
2. **이동** — `미성옥` 상세 → 길찾기(지하철/버스/도보 후보) → 이동 시작 → 패널 `승차 태그` →
   탑승 애니메이션 → 지도 위 경로 추적(캐릭터 이동) → 하차 알림 → 도착 모달
3. **방문 인증** — 도착 후 발도장 체크인(+10) → 리뷰 쓰기(현장 반경이라 방문 인증, +30)
4. **핫플** — 🔥 핫플 랭킹 시트에서 미성옥 순위·점수 상승 + `+오늘 내 방문` 칩 확인
5. **경제** — 결제 시뮬레이션(+50) → 지갑에서 잔액 변화·톡큰 내역·교통 잔액 이동 충전 확인
6. **어뷰징 방지** — 패널 `비현실적 점프 재현` → 체크인 시도 → 거부 토스트 → 정상 이동으로 해제

## 5분 데모 시나리오 (브리프 §8 수용 기준)

1. 온보딩에서 캐릭터 만들고 **주민증 발급**
2. 지도에서 `미성옥` 검색 → 상세 → 길찾기 → **승차 태그** → 탑승 애니메이션 → 도착
3. 가상 위치 이동 → **체크인 + 인증 리뷰** → 톡큰 토스트 → 🔥 핫플 랭킹 상승 확인
4. **명동성당** 근처로 이동 → 까치 **까미 조우 → 도감 등록** (+랜드마크 미니어처 획득)
5. **내 마을** 탭 → 드래그/WASD 로 마을 산책(카메라 추적) → 🎒 **배치 모드**(주민 잠시 퇴장,
   카메라 패닝) → 보관함에서 미성옥 건물(2×2)·까미 꺼내 드래그 → **✓ 배치 / ✕ 보관함** →
   완료 후 부엉 촌장에게 **말 걸기**(동숲풍 대화) → 풍성도가 오르면 새 동물 주민 입주
6. 커뮤니티(전체 통합 채널)에서 **검색·#태그 필터** → 영어 글 **번역 보기** → 패널 **Event Map
   토글**(광화문 콘서트) → 이벤트 배너 → 상세 안내(유의사항·부스·운영시간·길찾기) +
   까아미(한정 NPC) + 콘서트 응원봉(한정 소품) 확인

## 기술 스택

React 18 · Vite · TypeScript · Zustand(+persist) · Tailwind CSS · Leaflet(OSM)

```
src/
  assets/      코드 생성 SVG (캐릭터 파츠, NPC(까미·까아미·기본 4종), 건물, 랜드마크, 마커,
               차량, 톡페이 선불카드, 꾸미기 소품 9종)
  components/  frame(프레임·데모 패널) / onboarding / character / map / store / saved /
               journey / wallet / village(걷는 2.5D 마을·대화·상점·도감·주민증·꾸미기) /
               community / shell
  data/        seed.ts (매장 18곳·리뷰 42건·NPC·랜드마크·이벤트·Tokken 수치) +
               communitySeed.ts (커뮤니티 글 8건·분류 태그, 영↔한 번역 페어) +
               villageNpcs.ts (마을 주민 로스터·입주 조건·대사)
  mock/        목업 모듈 (가상 위치·가상 시계·톡페이 결제·승차 태그 — 실 API 교체형 인터페이스)
  store/       Zustand 스토어 (프로필/저장/UI/토스트/경제/방문/여정/마을/수집/이벤트/커뮤니티)
  lib/         로직 (핫플 랭킹, 목업 경로, 방문 루프 액션, NPC 로테이션) +
               마을 엔진 (villageWorld 지형 생성 · villageDraw 캔버스 드로잉 · villageGame 게임 루프)
```
