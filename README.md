# TokTown (톡타운) — 평가용 인터랙티브 데모

결제 서비스 '톡페이'의 확장 생태계 **TokTown**의 사내/투자 평가용 데모입니다.
지도·맛집 탐색·커뮤니티를 '동물의숲' 스타일 마을 세계관으로 감싸고, 실물 키링 교통카드(Town Key)로
온·오프라인을 연결하는 서비스의 핵심 루프를 브라우저에서 체험할 수 있습니다.

> 기획 근거: `toktown_기획문서_v1.7` · 구현 규칙: `toktown_구현브리프` (두 문서가 이 데모의 명세입니다)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 → 데스크톱 화면 중앙의 **모바일 프레임(390×844)** 안에서
앱이 실행되고, 프레임 밖에 시연용 **데모 컨트롤 패널**이 표시됩니다.

- 로그인/서버/외부 연동 없음 — 모든 데이터는 목업(`src/mock/`)이며 상태는 localStorage에 저장됩니다.
- 모든 그래픽은 코드로 생성한 SVG입니다(외부 이미지 0장).
- 지도 타일은 Leaflet + OpenStreetMap을 사용합니다. `tile.openstreetmap.org` 접근이 차단된
  네트워크(일부 사내 프록시)에서는 배경 타일만 비어 보일 수 있으며 마커·기능은 정상 동작합니다.
  실서비스 전환 시 네이버/카카오 지도 SDK로 교체 예정입니다.

## 마일스톤 진행 상황

| 단계 | 범위 | 상태 |
|---|---|---|
| **M1 — 셸 + 지도** | 온보딩(캐릭터 커스터마이징→주민증 발급), 하단 4탭, Leaflet 지도(명동 도보권), 커스텀 SVG 마커(매장/NPC/랜드마크/내 캐릭터), 검색·카테고리 칩, 매장 상세(리뷰·혜택·저장·길찾기 버튼), 저장 장소 | ✅ 완료 |
| M2 — 방문 루프 + 경제 | 가상 위치 컨트롤, 체크인/리뷰(반경 판정·인증 뱃지), Tokken 토스트, 핫플 랭킹, 지갑, 승차 태그→탑승 애니메이션→경로 추적, 출석 | 예정 |
| M3 — 내 마을 + 커뮤니티 + 이벤트 | 아이소메트릭 마을(그리드 배치), 건물/NPC/랜드마크 획득, Tokken 상점, 커뮤니티(번역 보기), Event Map, 주민증 | 예정 |

## M1 체험 가이드 (약 2분)

1. **온보딩** — 캐릭터 파츠(피부/헤어/의상) 커스터마이징 → 닉네임 → 주민증 발급 연출 → 촌장 부엉 튜토리얼
2. **지도** — 명동 도보권의 매장 핀 10곳, 까치 NPC(하루 2지점 로테이션), 랜드마크 4곳(명동성당·남산타워·청계천·광화문), 내 캐릭터 마커 탐색
3. **검색** — `미성옥` 검색(자동완성·최근 검색) → 매장 상세(혜택 뱃지·영업시간·주민 리뷰·방문 인증 뱃지)
4. **저장** — 상세에서 ❤️ 저장 → 칩 `저장` → `저장 목록 보기` → 지도에서 보기

## 기술 스택

React 18 · Vite · TypeScript · Zustand(+persist) · Tailwind CSS · Leaflet(OSM)

```
src/
  assets/      코드 생성 SVG (캐릭터 파츠, NPC 5종, 카테고리 건물, 랜드마크, 마커, 로고)
  components/  frame(모바일 프레임·데모 패널) / onboarding / map / store / saved / shell
  data/seed.ts 명동 시드 데이터 (매장 10곳·리뷰 34건·NPC·랜드마크·이벤트·Tokken 수치)
  mock/        목업 모듈 (가상 위치 등 — 실 API 교체 가능한 인터페이스 분리)
  store/       Zustand 스토어 (프로필/저장/UI/토스트, localStorage 영속)
  lib/         게임 로직 유틸 (NPC 출몰 로테이션 등)
```
